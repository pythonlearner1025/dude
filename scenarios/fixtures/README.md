# Scenario audio fixtures

The WAV files in this directory were generated with Breeze TTS 2 using a calm young-adult
voice, solely as synthetic player/dialogue inputs for the fake-game benchmark. Breeze TTS 2
is licensed for non-commercial use; keep these fixtures and their use within those terms.

`view.png` is a synthetic Halo-like test scene used only to exercise the kind-4 RGB protocol.
